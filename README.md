# Bedrock Structure Extractor

一个用于提取 Minecraft 基岩版世界中结构数据的 Termux / Node.js 工具。

## 环境
- Termux
- Node.js

## 安装
npm install

## 使用
node scan_db.mjs

## 说明
本工具用于读取 Bedrock 世界数据库中的结构数据并导出。
